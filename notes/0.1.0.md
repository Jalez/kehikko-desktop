- **Kehikot as a Mac app.** The first release of the desktop app. The Kehikot host is built in, so you open the app and your kehikot are there, with no separate server to start.
- **A calm start.** While Kehikot starts, the window shows its mark in your light or dark theme, and then opens your workspace. If the host stops, the window notices instead of waiting.
- **Feedback from inside the app.** Send feedback about Kehikot itself from beside the agent tools in the header.
