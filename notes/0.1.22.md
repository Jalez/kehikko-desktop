- **Notifications from every project.** Switching project no longer silences the others. The Inbox has a section for each other project, and pressing an item there opens that project and goes to it.
- **Installed modules stay current.** Before starting a module installed from the official list, Kehikot brings it up to its latest version.
- **The old "roadmap" name is gone.** Kehikot no longer reads modules or data under the name it had before. If you still had modules under that name, update to 0.1.24 or later, which carries them over.
