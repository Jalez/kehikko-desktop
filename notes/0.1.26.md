- **Renaming a project folder no longer breaks it.** Each project now carries its own identity inside its folder, so Kehikot knows it after a rename or move. If it can't find the folder, the project shows as **moved or renamed** with a **Locate…** button: pick the folder and everything (canvases, Inbox) is right where you left it. Adding a moved folder again also reconnects it instead of making a duplicate.
- **No more ghost folders.** Kehikot no longer recreates a project folder that was renamed, moved or deleted.
- **Release notes get to the point.** The release notes in Kehikot show only what's new.
- **A tidier project folder.** Kehikot's own files in each project move from `.kehikot/kehikko` to `.kehikot/host` the first time this version opens it. Older versions of Kehikot won't find them there, so update every Mac you use.
