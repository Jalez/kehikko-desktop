- **Opening Updates checks the app too.** Opening the Updates menu now looks for a new Kehikot version as well as module updates, so you no longer need **Check now** to see one.
- **Agents keep up with a moved project.** When an agent asks about a project by its old folder, Kehikot points it to where the project is now, instead of saying it isn't a project.
- **Pinned containers follow a moved project.** A pinned container now sees a renamed or moved project's new folder and keeps getting its updates.
