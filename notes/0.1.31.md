- **Each Claude conversation knows where it belongs.** A conversation started from a Claude container is recorded under its project, epic, parts and kehikko, so switching to another epic no longer confuses it. Its agent can ask with the new `my_place` tool, and tools answer about its own epic, saying when you're looking at something else.
- **See which conversation is this kehikko's own.** The Claude container's header names it. If you open a different one, it says so, with **Make this the kehikko's own** and **Back to its own**. Conversations started elsewhere show as **Not yet assigned**, ready to assign.
- **Module tools are connected for you.** A conversation started from Kehikot has the tools of every module on its kehikko connected from the start, with no plug to press.
- **New module: Editor.** Edit the file the canvas points at, with an explicit save that never overwrites a file changed on disk. Install it from the modules list.
