- **Set up your agent once, for every module.** Kehikot asks once whether it may keep Claude Code set up for you: every module's tools connected, and every module's skills installed and kept up to date, in every project. Each change it makes is one line in the Inbox, and it only ever changes what it added itself. Change it any time under **settings…** in the projects menu, and leave single modules out there.
- **Modules can offer Claude Code skills.** **Skills…** in a container's Frame menu shows the full text of a module's skills before you install or update them. A skill you have edited is never overwritten.
- **Assign a conversation from inside it.** Type `/kehikot-here` in a Claude Code conversation to file it under the kehikko on screen; you're told whether it became that kehikko's own conversation or the one it had stays.
