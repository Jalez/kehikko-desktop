- **Resize a container from any corner.** All four corners of a container now resize it, and the opposite corner stays where it is. The old grip is gone: a corner's rounded edge lights up softly when you hover it.
- **See where work stands on your board.** Issues and pull requests now carry their column from GitHub Projects or a GitLab board, so modules like Journeys and Flows can show it. For GitHub, allow reading your projects once with `gh auth refresh -s read:project`; Kehikot says so in the tracker sources if it can't read them yet.
