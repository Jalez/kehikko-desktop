- **Install a private module.** **Install from repository…** under **My modules** in the modules list adds a module from a repository only you can read: it checks it with your own `gh` or `glab` first, shows what it is, and installs it on this computer only. Modules you add are marked "added by you", get the same updates and version checks as official ones, never take an official module's port, and can be removed again.
- **Keep a module you installed by hand.** A module you put in place yourself is offered as "Keep it as one of my modules", so it updates and can be removed like the rest.
