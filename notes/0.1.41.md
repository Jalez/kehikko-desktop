- **Modules now have releases.** Every module has a version and release notes, and Kehikot installs and updates each one to its newest release instead of whatever was last merged. The Updates menu says what you'd get — "Journeys 1.5.0 → 1.6.0" — with **What's new** for every release since yours, and each container shows the version it runs.
- **Never moved backwards.** A module already running newer work than its latest release stays where it is until a newer release catches up, and a release that needs a newer Kehikot is skipped with a sentence saying so.
- **Pin a container to a release.** Pinning a container now names a release, such as 1.6.0.
