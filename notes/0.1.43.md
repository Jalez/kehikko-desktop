- **Settings you can find.** A gear in the top bar, or ⌘, opens Settings, now laid out in sections — Agents, Module tools, Skills, Tracker notices, Conversations, About — with a switch per setting that saves as you flip it, and a searchable list of modules showing each one's state in words.
- **Start a kehikko from a suggested layout.** A new kehikko can start from a ready arrangement — Build software, Write a paper, Plan an epic or Start simple — or from one saved in your project or for yourself with "save this kehikko as a layout…". Modules a layout needs are installed only when you confirm.
- **Layouts you can share.** A kehikko's arrangement stays in the project for everyone who opens it, while what you personally have open, folded or filtered now stays on your computer, so teammates no longer overwrite each other's view.
- **A short introduction and a tour.** New users get a five-step introduction to projects, epics, kehikot, the Inbox and Settings, then a guided tour of the app; both can be opened again from the ? button.
