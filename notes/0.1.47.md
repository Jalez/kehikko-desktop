- **GitLab tasks are tasks.** Kehikot now reads whether a GitLab item is a task, an incident, a test case or another work item type, so modules can treat a task as a task — Checklist's task checklists now apply to them.
- **Skills only where they work.** A skill that needs other modules on the same kehikko, such as `/review-factory` with Review and Factory, is no longer installed into every Claude Code conversation; Settings says where it's available, and Kehikot removes copies it installed before.
