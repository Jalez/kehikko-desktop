- **Switching kehikot is quick.** The modules of every kehikko in the open project now start in the background and keep running while the project is open, so switching to another kehikko shows them in well under a second instead of several. Turn it off under Settings › Module tools › "Keep this project's modules running" if you'd rather save memory.
- **Modules start without waiting for updates.** A module starts straight away; a newer release found meanwhile is put in place the next time the module stops or restarts.
- **Keystrokes stay where you can see them.** A kehikko you just left stays loaded for an instant switch back, and its hidden pages can no longer take the keyboard focus.
