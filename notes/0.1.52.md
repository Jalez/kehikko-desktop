- **A project's base branch.** Settings › Project sets the branch work starts from and updates come from — such as `development` — for everyone on the project; Kehikot checks that the branch exists before saving it, and tells modules and agents.
- **Clear words when git needs you.** When your SSH key is locked with a passphrase, a host's key is unknown or changed, or a sign-in is needed, Kehikot now says exactly that, with the command to run in Terminal and a Retry button, instead of "could not be reached". It never asks for your passphrase itself.
