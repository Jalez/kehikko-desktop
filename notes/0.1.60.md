- **Template cards fit.** In the New kehikko window, each template's modules wrap inside its card instead of running past it; a long list shows the first few and "+N more", and a long name is shortened with its full name on hover.
- **Linked branches are read.** Kehikot now reads which branches are linked to an issue (GitHub's Development section, and GitLab branches named after the issue), without extra requests, so a board can show work that has started.
- **Modules can read issues without their page open.** A module's own server can now ask Kehikot for the issues it may see, so Claude can read the Kanban board even when no board is on screen.
