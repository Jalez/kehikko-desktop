- **See what Kehikot sends and receives.** Kehikot now keeps a short record, on this computer only, of the calls it and its modules make — when, to where, and why — and of the connections each module holds open. The new Monitor module shows it as a live timeline, finds calls that are repeated with the same answer, and shows how much of the GitHub request budget is left. Tokens and query values are never recorded, nor what a call sends or receives.
