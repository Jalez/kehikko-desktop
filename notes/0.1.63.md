- **Far fewer repeated calls.** Kehikot no longer re-reads every module's description every few seconds, opens the page with one request of each kind instead of a burst of duplicates, and checks for module updates by asking the remote what changed before fetching anything. In a two-minute test with two pages open that is 50 calls instead of 139, and no module descriptions re-read at all instead of 69.
- **Your own checkouts are left alone.** A module checkout you edit is no longer fetched in the background; the Updates menu says when it has new commits, and Check now fetches them.
