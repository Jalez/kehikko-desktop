- **Any module can share an epic's plan.** Kehikot now gathers the steps, phases and gates of an epic from every module that publishes them, instead of only from Journeys, and tells each module where each step came from. Nothing changes for you until modules start publishing.
- **Skills follow what is on the kehikko.** A skill can now ask for "something that keeps the steps" rather than one named module, and skills meant for an agent go to whichever module runs agent sessions.
- **Modules ask instead of reading each other's files.** A module's own server can now ask Kehikot for epics, steps, parts and why issues closed, with the same permissions as its page.
