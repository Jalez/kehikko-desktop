- **A module that doesn't fit says so.** When a module needs a newer Kehikot, its container now says so in place of a broken page — what it uses that this Kehikot lacks, and an Update Kehikot button. A module too old for this Kehikot asks to be updated instead. This works for every module, including ones you build yourself.
- **What's new shows each release once.** A module's notes are no longer repeated, and the "works with" line appears once.
- **The introduction fits your setup.** It no longer assumes every kehikko has a Claude conversation, and it mentions that your agent can build a module of your own with /kehikot-module.
