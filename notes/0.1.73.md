- **A kehikko fills to the bottom.** Rows now fit the window exactly, so a container stretched to the bottom ends the same small distance from the edge as on the right, with no band left over. There are twice as many rows, so resizing moves in finer steps; your layouts look exactly as before. A layout you change is saved in the finer form, which an older Kehikot can't read until it is updated.
- **Headers never overlap.** In a narrow container, the branch or release label shrinks to its icon, then the version hides, and the name is shortened with its full text on hover — the name, version and label are never drawn over each other.
