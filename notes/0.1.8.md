- **Divide an epic into parts.** A large epic can be split into parts, and a new control beside the epic in the bar lets you focus on one or several while the rest stays visible. Modules are told which parts you picked. A project where you picked parts can't be opened by older versions of Kehikot.
- **Steps from Journeys.** When a project uses the Journeys module, Kehikot reads an epic's steps and parts from it.
- **Retrying an install works.** Installing a module again after a failed attempt now picks up where the last one stopped.
