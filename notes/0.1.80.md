- **See and change how modules affect each other.** Every module's settings gear now opens a window with a Providers & Consumers tab: what the module gives the others on this kehikko, what it takes from them, and a switch for each — for example so Notes doesn't follow Paper's passage here. Where several modules provide the same thing, you can pick which one counts. The switches belong to the kehikko and travel with the project; an older Kehikot can't read a layout that has them.
