- **Updates finish even if you click away.** Closing the Updates panel, or reloading, no longer stops an update; reopen the panel to see how far it has got. Its Cancel button is the only way to stop one.
- **Restart a module.** Each module's Run menu has Restart module, which restarts just that module. If it does not come back, you see its last log lines and a Retry button.
- **Your agent can take you somewhere.** Ask an agent session to take you to another project, kehikko, epic, part or step, and it goes there. The kehikko then shows Go back, which returns you to exactly where you were.
- **A step picked in one module now turns the others to it,** as it was meant to.
